# ☕ 댕댕 카페 랜딩 페이지

간단한 카페 소개용 정적 랜딩 페이지입니다. 별도의 빌드 과정 없이 HTML과 CSS만으로 만들었습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 카페 소개, 오시는 길, 푸터) |
| `style.css` | 스타일시트 (카페 분위기의 갈색 톤, 모바일 반응형 포함) |

## 실행 방법

`index.html` 파일을 브라우저(Chrome 등)로 열면 바로 확인할 수 있습니다.

## 수정 안내

가게 이름, 메뉴, 가격, 주소, 전화번호는 예시 값입니다. 실제 정보에 맞게 `index.html`에서 수정해 사용하세요.
